    Properties

    Name Type Description Notes
    IsDeleteOnTermination Pointer to NullableBool 인스턴스 삭제 시 해당 볼륨을 자동으로 삭제할지 여부 - 첫 번째 볼륨: 기본값 `true` - 두 번째 이후 볼륨: 기본값 `false` [optional]
    Size Pointer to NullableInt32 볼륨의 크기(GB) - 허용 범위: 1 ~ 16384 - `source_type = image`일 경우, 해당 이미지의 `min_disk` 이상이어야 하며, Windows 이미지의 경우 최대 2048GB까지 지원 [optional]
    SourceType Pointer to NullableSourceType 볼륨의 소스 유형 - 첫 번째 이후 볼륨의 기본값은 `blank` [optional]
    Uuid Pointer to NullableString `source_type`에 따라 입력 값이 달라짐 - `volume`: 기존 볼륨 ID(List volumes에서 확인) - `image`: 이미지 ID(기본값은 요청 바디의 `instance.image_id`) - `null`: 사용 안함 - `blank`: 생략 [optional]
    TypeId Pointer to NullableString 연결할 블록 스토리지의 볼륨 유형 ID, 현재는 `gp2`(범용 SSD)만 지원 - `source_type = image` 또는 `blank`일 때만 입력 - List volume types에서 확인 [optional]
    EncryptionSecretId Pointer to NullableString 암호화 키 ID - 기존 `encryption_secret_uuid` 필드명이 `encryption_secret_id`로 변경됨 - 현재 `encryption_secret_uuid`로 요청을 보내도 처리되지만, 향후 deprecated 예정이므로 사용을 권장하지 않음 - `encryption_secret_id`와 `encryption_secret_uuid`를 동시에 전달할 경우, `encryption_secret_id`만 사용되어 처리됨 [optional]
