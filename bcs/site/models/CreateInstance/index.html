    CreateInstance

    Properties

    Name Type Description Notes
    Name string 생성할 인스턴스의 이름 - 같은 프로젝트 내 중복된 인스턴스 이름 사용 가능
    Description Pointer to NullableString 인스턴스에 대한 설명 [optional]
    Count Pointer to int32 생성할 인스턴스 수 [optional] [default to 1]
    ImageId string 이미지의 고유 ID - List images에서 확인
    FlavorId string 인스턴스 유형 ID - List instance types에서 확인
    AvailabilityZone Pointer to NullableAvailabilityZone 인스턴스를 생성할 가용 영역 - 미 입력 시 입력한 `subnets[].id`에 맞는 가용 영역에 자동 생성 [optional]
    Subnets []SubnetRequest 연결할 서브넷 정보 목록
    Volumes Pointer to []BlockDeviceMappingRequest 인스턴스에 연결할 볼륨 [optional]
    KeyName Pointer to NullableString 인스턴스에 등록할 SSH 키 이름 - List keypairs에서 확인 [optional]
    SecurityGroups Pointer to []SecurityGroupRequest 인스턴스에 적용할 보안 그룹 [optional]
    UserData Pointer to NullableString 인스턴스 시작 시, 사용자 데이터를 실행하여 초기 환경 구성을 자동으로 실행하는 스크립트(인스턴스 최초 시작 시에만 실행됨) - 사용자 데이터 스크립트 및 `cloud-init` 명령을 16KB 이내로 입력 - 사용자 스크립트는 Base64 인코딩된 문자열로 입력 - 스크립트는 `/var/lib/cloud/instances` 하위에 복사되어 실행 - 스크립트 실행 로그 확인 시 다음 명령어 실행 ㄴ Ubuntu: `sudo cat /var/log/syslog 또는 sudo journalctl -u cloud-final.service` ㄴ CentOS: `sudo cat /var/log/messages 또는 sudo journalctl -u cloud-final.service` ⚠️ 잘못된 사용자 스크립트를 입력하거나 실행이 완료되지 않는 스크립트를 입력할 시, 부팅에 실패할 수 있습니다. [optional]
    IsDisableHyperThreading Pointer to NullableBool 하이퍼스레딩 비활성화 여부 [optional]
    IsBonding Pointer to NullableBool 네트워크 인터페이스 본딩 설정 여부 - 베어메탈(`bm`) 유형을 생성할 경우에만 입력 필요 [optional]
