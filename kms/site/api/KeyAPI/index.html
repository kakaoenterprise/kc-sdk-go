    고수준 클라이언트를 먼저 확인하세요

    이 페이지는 저수준(raw) 빌더 API입니다. 대부분의 경우 Getting Started의 고수준 클라이언트(client.Key.<오퍼레이션>(ctx, ...) 형태, 직접 인자 스타일)로 충분합니다. Execute() 체인이 직접 필요한 경우에만 이 페이지를 참고하세요.

    \KeyAPI

    All URIs are relative to https://key-management-service.kr-central-2.kakaocloud.com

    Method HTTP request Description
    AddUserKeyAccessTargets Post /api/v1/keys/{key_id}/access-control/targets Add user key access targets
    BulkDeleteUserKeys Post /api/v1/keys/deletions Bulk delete user keys
    CreateUserKey Post /api/v1/keys Create user key
    DeleteUserKey Delete /api/v1/keys/{key_id} Delete user key
    GetKey Get /api/v1/keys/{key_id} Get key
    GetKeyByName Get /api/v1/keys/name/{key_name} Get key by name
    GetPublicKey Get /api/v1/keys/{key_id}/public-key Get public key
    ListKeyAlgorithms Get /api/v1/algorithms List key algorithms
    ListServiceKeys Get /api/v1/service-keys List service keys
    ListSymmetricKeys Get /api/v1/symmetric-keys List symmetric keys
    ListUserKeyAccessTargets Get /api/v1/keys/{key_id}/access-control/targets List user key access targets
    ListUserKeys Get /api/v1/keys List user keys
    RemoveUserKeyAccessTargets Post /api/v1/keys/{key_id}/access-control/targets/deletions Remove user key access targets
    UpdateUserKeyAccessControl Put /api/v1/keys/{key_id}/access-control Update user key access control
    UpdateUserKeyRotation Patch /api/v1/keys/{key_id}/rotation Update user key rotation
