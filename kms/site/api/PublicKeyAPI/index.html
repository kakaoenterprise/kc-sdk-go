    \PublicKeyAPI

    All URIs are relative to https://key-management-service.kr-central-2.kakaocloud.com

    Method HTTP request Description
    CreateDataKey Post /api/v1/keys/{key_id}/data-key Create data key
    DecryptData Post /api/v1/keys/{key_id}/decrypt Decrypt data
    EncryptData Post /api/v1/keys/{key_id}/encrypt Encrypt data
    GenerateHmac Post /api/v1/keys/{key_id}/hmac Generate HMAC
    SignData Post /api/v1/keys/{key_id}/sign Sign data
    VerifyHmac Post /api/v1/keys/{key_id}/hmac/verify Verify HMAC
    VerifySignature Post /api/v1/keys/{key_id}/sign/verify Verify signature

    CreateDataKey
