    고수준 클라이언트를 먼저 확인하세요

    이 페이지는 저수준(raw) 빌더 API입니다. 대부분의 경우 Getting Started의 고수준 클라이언트(client.PublicIP.<오퍼레이션>(ctx, ...) 형태, 직접 인자 스타일)로 충분합니다. Execute() 체인이 직접 필요한 경우에만 이 페이지를 참고하세요.

    \PublicIPAPI

    All URIs are relative to https://network.kr-central-2.kakaocloud.com

    Method HTTP request Description
    CreatePublicIp Post /api/v1/public-ips Create public IP
    DeletePublicIp Delete /api/v1/public-ips/{public_ip_id} Delete public IP
    GetPublicIp Get /api/v1/public-ips/{public_ip_id} Get public IP
    ListPublicIps Get /api/v1/public-ips List public IPs
    UpdatePublicIp Put /api/v1/public-ips/{public_ip_id} Update public IP
