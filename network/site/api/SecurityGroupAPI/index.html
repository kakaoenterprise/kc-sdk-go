    \SecurityGroupAPI

    All URIs are relative to https://network.kr-central-2.kakaocloud.com

    Method HTTP request Description
    CreateSecurityGroup Post /api/v1/security-groups Create security group
    CreateSecurityGroupRule Post /api/v1/security-groups/{security_group_id}/rules Create security group rule
    DeleteSecurityGroup Delete /api/v1/security-groups/{security_group_id} Delete security group
    DeleteSecurityGroupRule Delete /api/v1/security-groups/{security_group_id}/rules/{security_group_rule_id} Delete security group rule
    GetSecurityGroup Get /api/v1/security-groups/{security_group_id} Get security group
    ListSecurityGroups Get /api/v1/security-groups List security groups
    UpdateSecurityGroup Put /api/v1/security-groups/{security_group_id} Update security group
