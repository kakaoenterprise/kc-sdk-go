    고수준 클라이언트를 먼저 확인하세요

    이 페이지는 저수준(raw) 빌더 API입니다. 대부분의 경우 Getting Started의 고수준 클라이언트(client.Secret.<오퍼레이션>(ctx, ...) 형태, 직접 인자 스타일)로 충분합니다. Execute() 체인이 직접 필요한 경우에만 이 페이지를 참고하세요.

    \SecretAPI

    All URIs are relative to https://secrets-manager-service.kr-central-2.kakaocloud.com

    Method HTTP request Description
    AddSecretsAccessTargets Post /api/v1/secrets/{secret_id}/access-control/targets Add secret access targets
    BulkDeleteSecrets Post /api/v1/secrets/deletions Bulk delete secrets
    CreateSecret Post /api/v1/secrets Create secret
    DeleteSecret Delete /api/v1/secrets/{secret_id} Delete secret
    GetSecret Get /api/v1/secrets/{secret_id} Get secret
    ListSecrets Get /api/v1/secrets List secrets
    ListSecretsAccessTargets Get /api/v1/secrets/{secret_id}/access-control/targets List secret access targets
    RemoveSecretsAccessTargets Post /api/v1/secrets/{secret_id}/access-control/targets/deletions Remove secret access targets
    UpdateSecretKmsKey Patch /api/v1/secrets/{secret_id}/kms-key Update secret KMS key
    UpdateSecretsAccessControl Put /api/v1/secrets/{secret_id}/access-control Update secret access control
