    \TransitGatewayAttachmentAPI

    All URIs are relative to https://tgw.kr-central-2.kakaocloud.com

    Method HTTP request Description
    ApproveTgwAttachment Put /api/v1/attachments/{attachment_id}/approve Approve TGW attachment
    CreateTgwAttachment Post /api/v1/attachments Create TGW attachment
    DeleteTgwAttachment Delete /api/v1/attachments/{attachment_id} Delete TGW attachment
    GetTgwAttachment Get /api/v1/attachments/{attachment_id} Get TGW attachment
    ListTgwAttachments Get /api/v1/attachments List TGW attachments
    RejectTgwAttachment Put /api/v1/attachments/{attachment_id}/reject Reject TGW attachment
    UpdateTgwAttachment Put /api/v1/attachments/{attachment_id} Update TGW attachment
