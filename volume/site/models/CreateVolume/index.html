    Properties

    Name Type Description Notes
    Name string 생성할 볼륨의 이름
    Description Pointer to NullableString 볼륨에 대한 설명 [optional]
    Size int32 볼륨 크기 (GB 단위) - Linux 계열: 1 ~ 16,384 GB - Windows 계열: 1 ~ 2,048 GB
    AvailabilityZone AvailabilityZone 볼륨을 생성할 가용 영역
    VolumeTypeId Pointer to NullableString 볼륨 유형 ID - List volume types에서 확인 [optional]
    SourceVolumeId Pointer to NullableString 원본 볼륨 ID - List volumes에서 확인 [optional]
    EncryptionSecretId Pointer to NullableString 암호화 키 ID - 기존 `encryption_secret_uuid` 필드명이 `encryption_secret_id`로 변경됨 - 현재 `encryption_secret_uuid`로 요청을 보내도 처리되지만, 향후 deprecated 예정이므로 사용을 권장하지 않음 - `encryption_secret_id`와 `encryption_secret_uuid`를 동시에 전달할 경우, `encryption_secret_id`만 사용되어 처리됨 [optional]
    ImageId Pointer to NullableString 이미지의 고유 ID - List images에서 확인 [optional]
