    Name Type Description Notes
    Id string 볼륨 ID
    Size Pointer to NullableInt32 볼륨 크기 (Bytes 단위) [optional]

    Name Pointer to NullableString 볼륨 이름 [optional]
    Description Pointer to NullableString 볼륨에 대한 설명 [optional]

    IsEncrypted Pointer to NullableBool 암호화 여부 [optional]

    Type Pointer to NullableString 스토리지 유형 [optional]
    UserId Pointer to NullableString 볼륨 소유 사용자 ID [optional]
    ProjectId Pointer to NullableString 볼륨이 속한 프로젝트 ID [optional]
    AvailabilityZone Pointer to NullableAvailabilityZone 볼륨이 생성된 가용 영역 [optional]
    AttachStatus Pointer to NullableString 볼륨 연결 상태 [optional]
    LaunchedAt Pointer to NullableTime 볼륨이 인스턴스에 마지막으로 연결된 시각 [optional]
    EncryptionKeyId Pointer to NullableString 볼륨 암호화에 사용된 키의 ID [optional]
    PreviousStatus Pointer to NullableString 이전 상태 [optional]
    CreatedAt Pointer to NullableTime 리소스가 생성된 시간 - ISO 8601 형식 - UTC 기준 [optional]
    UpdatedAt Pointer to NullableTime 리소스가 마지막으로 수정된 시간 - ISO 8601 형식 - UTC 기준 [optional]
    InstanceId Pointer to NullableString 인스턴스의 고유 ID [optional]
    InstanceName Pointer to NullableString 연결된 인스턴스 이름 [optional]
    ImageMetadata Pointer to NullableImageMetaData 이미지에서 생성된 경우 해당 메타데이터 [optional]
    VolumeType Pointer to NullableString 볼륨 유형 [optional]
