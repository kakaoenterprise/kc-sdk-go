    AvailabilityZone Pointer to NullableAvailabilityZone 볼륨이 위치한 가용 영역 [optional]
    CreatedAt Pointer to NullableTime 리소스가 생성된 시간 - ISO 8601 형식 - UTC 기준 [optional]
    UpdatedAt Pointer to NullableTime 리소스가 마지막으로 수정된 시간 - ISO 8601 형식 - UTC 기준 [optional]

    Metadata map[string]string 볼륨에 설정된 사용자 정의 메타데이터(Key-Value 쌍)
    UserId Pointer to NullableString 볼륨을 소유한 사용자 ID [optional]
    IsEncrypted Pointer to NullableBool 암호화 여부 [optional]
    Attachments []Attachment 볼륨의 인스턴스 연결 상태를 나타내는 Attachment 목록 - 새로 생성된 볼륨은 일반적으로 빈 배열
    IsBootable bool 부팅 가능 여부
