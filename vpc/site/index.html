    kc-sdk-go/v2/services/vpc

    KakaoCloud SDK 서비스 진입점(스펙 기반 생성 인터페이스).

    사용 예

    import (
    "github.com/kakaoenterprise/kc-sdk-go/v2/config"
    "github.com/kakaoenterprise/kc-sdk-go/v2/services/vpc"
)

cfg, err := config.LoadDefaultConfig(ctx)
client := vpc.NewFromConfig(cfg)

resp, err := client.InternetGateway.CreateInternetGateway(ctx, *vpc.NewCreateInternetGatewayRequest(
    *vpc.NewCreateInternetGateway(),
))

    저수준 빌더 인터페이스(Execute 체인)가 필요하면 NewAPIClient를 직접 사용합니다.

    사용 가능한 리소스와 오퍼레이션

    InternetGateway

    client.InternetGateway.<오퍼레이션>(ctx, ...)

    • CreateIgwAttachment — Create IGW attachment
    • CreateInternetGateway — Create internet gateway
    • DeleteIgwAttachment — Delete IGW attachment
    • DeleteInternetGateway — Delete internet gateway
    • GetInternetGateway — Get internet gateway
    • ListInternetGateways — List internet gateways
    • UpdateInternetGateway — Update internet gateway

    NetworkInterface

    client.NetworkInterface.<오퍼레이션>(ctx, ...)

    • CreateNetworkInterface — Create network interface
    • DeleteNetworkInterface — Delete network interface
    • GetNetworkInterface — Get network interface
    • ListNetworkInterfaces — List network interfaces
    • UpdateNetworkInterface — Update network interface
    • UpdateNetworkInterfaceAllowedAddresses — Update network interface allowed addresses

    Subnet

    client.Subnet.<오퍼레이션>(ctx, ...)

    • CreateSubnet — Create subnet
    • DeleteSubnet — Delete subnet
    • GetSubnet — Get subnet
    • ListSubnetSharedProjects — List subnet shared projects
    • ListSubnets — List subnets
    • ShareSubnet — Share subnet
    • UnshareSubnet — Unshare subnet
    • UpdateSubnet — Update subnet

    VPC

    client.VPC.<오퍼레이션>(ctx, ...)

    • CreateVpc — Create VPC
    • DeleteVpc — Delete VPC
    • GetVpc — Get VPC
    • ListVpcs — List VPCs
    • UpdateVpc — Update VPC

    VPCRouteTable

    client.VPCRouteTable.<오퍼레이션>(ctx, ...)

    • AddRoute — Add route
    • CreateRouteTable — Create route table
    • DeleteRoute — Delete route
    • DeleteRouteTable — Delete route table
    • GetRouteTable — Get route table
    • ListRouteTableAssociations — List route table associations
    • ListRouteTables — List route tables
    • SetMainRouteTable — Set main route table
    • UpdateRoute — Update route
    • UpdateRouteTable — Update route table
    • UpdateRouteTableAssociation — Update route table association
